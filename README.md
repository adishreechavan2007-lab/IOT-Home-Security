# 🏠 IOT-Home-Security

**IoT-Based Home Security System - ESP32 + PIR + Door Sensor with Live Dashboard**

## 🚀 Live Demo
Run `python app.py` in Codespaces -> Open port 8080 -> Dashboard shows SAFE/ALERT in real-time.

![Dashboard](https://img.shields.io/badge/Status-Live-green) ![ESP32](https://img.shields.io/badge/Hardware-ESP32-blue)

## 🛠️ Tech Stack
- **Hardware:** ESP32, PIR Motion Sensor, Magnetic Door Sensor, Buzzer
- **Software:** Python Flask, Blynk IoT, Arduino IDE
- **Languages:** Python, C++ (Arduino), HTML

## 📂 Project Structure
- `app.py` - Web dashboard with live simulation
- `ESP32_Code/` - Actual hardware code (coming soon)

## ✨ Features
- Real-time motion detection
- Door open/close alerts
- Buzzer alarm + Mobile notification via Blynk
- Web dashboard with auto-refresh
