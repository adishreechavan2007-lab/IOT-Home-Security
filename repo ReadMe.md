#  IoT-Based Home Security System
> "Enhancing safety with smart tech" - by Adishree Chavan, SE Computer

A smart, affordable IoT solution with real-time monitoring and instant mobile alerts.

###  Tech Stack I Used
**Hardware:** ESP32, PIR Motion Sensor, Buzzer, LED, WiFi Module
**Software:** C, Python, HTML, JavaScript, Flask, Telegram Bot API, Firebase (Future)

###  What it does
- Detects motion via PIR sensor
- Sends instant Telegram/Email alert if system is armed
- Dashboard to Arm/Disarm remotely
- Future: Gas detection, Smart CCTV, Face Recognition
